Español: README
Título del Proyecto: Juego de Plataformas Educativo

Descripción:
Este proyecto es un videojuego de plataformas desarrollado en Python utilizando la librería Pygame. El juego integra un sistema de quiz educativo con 100 preguntas en alemán, generando niveles de forma procedural.

Requisitos previos:

Tener instalado Python 3.x.

Instalar la librería Pygame ejecutando: pip install pygame

Estructura del proyecto:

main.py: Contiene la lógica principal del bucle de juego, la gestión de estados (Pausa, Game Over, Quiz, Campeón) y el banco de preguntas.

player.py: Define las clases Jugador, Plataforma y Moneda, incluyendo la física del personaje.

Recursos: Asegúrate de que los archivos jugador.png, fondo.png, piso.png, bloque.png y los archivos de sonido (walk.wav, jump.wav, gameover.wav) estén en la misma carpeta que los scripts.

Instrucciones de ejecución:

Navega a la carpeta del proyecto en tu terminal.

Ejecuta el juego con el comando: python main.py

Controles:

Flechas izquierda/derecha: Movimiento.

Flecha arriba: Saltar.

Enter: Pausa.

Durante la pausa: [W] para continuar, [R] para reiniciar, [A] para salir.

Deutsch: README
Projekttitel: Bildungs-Plattformer-Spiel

Beschreibung:
Dieses Projekt ist ein mit Python und der Pygame-Bibliothek entwickeltes Plattform-Spiel. Das Spiel integriert ein pädagogisches Quiz-System mit 100 Fragen auf Deutsch und generiert Level prozedural.

Voraussetzungen:

Installiertes Python 3.x.

Installieren Sie die Pygame-Bibliothek mit dem Befehl: pip install pygame

Projektstruktur:

main.py: Enthält die Haupt-Spielelogik, die Zustandsverwaltung (Pause, Game Over, Quiz, Champion) und die Fragenbank.

player.py: Definiert die Klassen Jugador (Spieler), Plataforma (Plattform) und Moneda (Münze), einschließlich der Physik.

Ressourcen: Stellen Sie sicher, dass sich jugador.png, fondo.png, piso.png, bloque.png sowie die Sounddateien (walk.wav, jump.wav, gameover.wav) im selben Ordner wie die Skripte befinden.

Ausführung:

Navigieren Sie in Ihrem Terminal zum Projektordner.

Starten Sie das Spiel mit: python main.py

Steuerung:

Links/Rechts-Pfeiltasten: Bewegung.

Pfeiltaste hoch: Springen.

Enter: Pause.

Im Pausenmenü: [W] für Weiter, [R] für Restart, [A] für Aus.
